# mlops-learn

Learning MLOps and LLMOps in public.

## Resources used

Below are all the sources used for this educational project:

* **MLOps zoomcamp**, provided by the DataTalks team. All source code and video materials are at this [repo](https://github.com/DataTalksClub/mlops-zoomcamp).
It covers:
  * Practical e2e MLOps, such as experiment tracking and model management with MLFlow.
  * Workflow orchestration with Prefect, Mage, and AirFlow.
  * Model deployment: providing batch and web services with FastAPI and Docker, and handling deployment with AWS Elastic Beanstalk and K8s
  * Model monitoring: tracking model performance with Evidently and Grafana, covering data and concept drift.
  * Best practices and CI/CD in ML using Git and setting up automated CI/CD deployment pipelines.
* **MLOps, Machine Learning Operations Specialization**, offered by Duke University, on [Coursera](https://www.coursera.org).
It covers:
  * Python recap and Rust introduction for GPU acceleration for ML tasks.
  * DevOps, DataOps, and microservices, including CI pipelines with GitHub Actions, and containerising applications with Docker.
  * Enterprise cloud platforms such as Amazon Sagemaker and Microsoft Azure ML for focusing on managing infrastructure and production workloads.
  * Open-source tools like MLFlow, and modern LLMOps concepts: fine-tuning, operationalising, and deploying LLMs (ONNX) with Hugging Face
